# Step 7 委托编排证据（2026-08-31）

任务：「两组城市平均温度比较」（北京+上海 vs 广州+深圳，哪组更热；正确答案：广深组，32.5 vs 29.5）

| 路径 | LLM 调用 | 父上下文污染 | 行为 |
|---|---|---|---|
| direct/（无 --delegate） | **3 次**（4 工具同轮并行 + 心算聚合） | 4 条 tool 消息 | 模型务实直做，答案正确 |
| delegated/（--delegate + 显式拆分指令） | 8 次（父 2 + 子 3×2） | **仅 2 条摘要信封** | 父并行分解 → 子各 3 轮（weather×2+calculate）→ 聚合正确（含 3°C 温差） |

三次实测的行为学观察：
1. 工具直接可见时模型**从不过度委托**（两次自发直做）——委托只在显式要求或子任务足够重时发生
2. 同轮多 delegate = 协议原生并行分解（AC-4 机制的直接复用）
3. 委托的成本是 LLM 调用数 ~2.7×，收益是父上下文干净（摘要信封 vs 全部过程消息）——
   隔离是为复杂任务买的空间，简单任务不值得（AC7-3 结论）
