# 从零手搓本地 Agent · 教程

> 这不是一本"讲讲 agent 概念"的书。这是一份**构建日志**：跟着它从头敲到尾，
> 你会亲手搓出一个跑在自己电脑上、能查数据、会算数、打不死的真 agent——
> 以及一整套让你确信"它真的在工作"的证据制度。

## 本教程怎么教（组织原则）

1. **按版本里程碑组织**：agent 的能力一次只长一点。v0.1 只会说一句话，
   v0.4 第一次自己调工具，v0.12 通过全部大考。**每个版本结束，项目都能跑**——
   你随时停下来，手里都是一个完整的东西
2. **抽丝剥茧**：每个机制都从最笨的做法开始，**亲手撞墙**（贴崩溃现场原文），
   分析根因，再推导出正确做法。正确答案不是宣布的，是被墙撞出来的
3. **代码完整**：每个版本的每个文件给全量代码，照抄能跑。省略号是概览书的病，
   本书没有
4. **每个决定都有取舍**：为什么这样不那样，失败的方案死在哪，全部记录
5. **真机数据**：所有数字（速度/成功率/命中率）来自实测，报错贴原文

## 读者假设与平台

- 会开机复制粘贴，**愿意学命令行**（第 0 章带你过门槛，不绕）
- 不需要会编程、不需要懂 AI、不需要显卡（全程 CPU 实证）
- **Windows 主线**（每条命令可复制），Mac 附注；代码只用跨平台 API，
  方法不绑定平台

## 工程纪律（贯穿全书，每章自测清单都含）

1. 不引框架不引 SDK：SSE、JSON Schema、循环全部手写
2. 大脑零依赖（仅 zod）：一份代码从终端跑到手机
3. 每次与模型的通信必须存证（请求+响应原文落盘）
4. 功能先写测试（测试是行为的精确定义）
5. 每个功能亲眼看过它失败的样子，才算做过
6. 结论要有证据，成败看退出码

## 本教程的代码经过验证

全书代码在独立工作区经过三级验证：**编译**（两册全部代码块拼合，零错误）、
**测试**（单元测试全绿）、**真机端到端**（本地引擎跑通"调工具取数→正确终答/
失败不编造/故障注入自愈"三类场景）。骨架级代码（方法体留给读者的展示段）
经过签名兼容性编译——引用的类型链全部真实存在。

验证确立的一条原则值得记住：**编译绿、测试绿 ≠ 工具真的发出去了**——
行为正确只有端到端能证明。这也是各章"搞坏实验"存在的理由。
