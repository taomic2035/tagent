# 从零手搓本地 Agent · 教程

> 一册在手，带你从零写出一个跑在自己电脑上的 agent：它会自己决定调用工具、
> 会处理失败、会管好自己的记忆。不依赖任何 agent 框架，大脑部分只有一个依赖（zod）。
>
> 教程与参考实现 [tagent](../README.md) 同源：所有命令、参数、报错、实验数据
> 都来自真机实操，报错贴原文，数据可复现。

## 读者假设

- 会开机、会复制粘贴；**愿意学命令行**（第 0 章带你过最低配置，不帮你绕）
- 不需要会编程、不需要懂 AI、不需要显卡（全程 CPU 实证，慢但完全可用）
- 平台：**Windows 为主线**（每条命令可复制），Mac 以附注形式补充。
  所有代码只用跨平台 API——**本教程的方法不绑定任何平台**，Linux 同样适用

## 本教程的工程纪律（全书贯穿，每章自测清单都含）

1. **不引框架、不引 SDK**：SSE 解析、JSON Schema 生成、agent 循环全部手写——
   你要学的是原理，框架会替你挡掉 exactly 你该学的东西
2. **大脑零依赖**（允许 zod 一个）：保证这份代码从终端跑到手机都不用改
3. **每次与模型的通信必须存证**：请求体、响应原文落盘，事后可追溯
4. **功能先写测试**：每个行为先有测试再有实现，改坏立刻知道
5. **故意搞坏**：每个功能都要亲眼看过它失败的样子，才算做过
6. **结论要有证据**：说"快了 40%"就要有存档数据，不接受"感觉"

## 学法建议

- 按章序读，每章的"动手做"必须亲手敲（复制粘贴也行，但要看懂每一行再贴）

- 卡住时先看"常见坑"，再看参考实现的对应测试文件——测试就是行为的精确定义
